# Галерея

Минималистичный интернет-магазин репродукций картин на React (Vite).

- Каталог с фильтрами по жанру и художнику
- Страница картины: материал (бумага / холст), размер, рама, цена, увеличение изображения, похожие работы
- Корзина с количеством, оформление заказа (доставка, оплата, согласие на обработку данных)
- Страницы «Доставка и оплата», «О галерее», «Политика конфиденциальности»

Изображения — открытая коллекция Art Institute of Chicago (общественное достояние, CC0), лежат в `public/art/`.

## Настройка

- Контакты и название — `src/config.js`
- Цены, размеры, доставка — `src/data.js`
- Картины и описания — `src/artworks.js`
- Приём заказов: создайте форму на [Formspree](https://formspree.io) (или любой сервис, принимающий POST JSON)
  и добавьте URL в репозитории: **Settings → Secrets and variables → Actions → Variables → `ORDER_ENDPOINT`**.
  Без неё при оформлении открывается почтовый клиент с готовым письмом на `contactEmail`.

## Разработка

```bash
npm install
npm run dev
npm run build
```

Деплой — автоматически на GitHub Pages при пуше (`.github/workflows/deploy.yml`).
