# Галерея

Минималистичный сайт-галерея на React (Vite): каталог картин, страница работы, корзина и оформление заказа.

```bash
npm install
npm run dev     # локально
npm run build   # сборка в dist/
```

Деплой — автоматически на GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`).
Картины и цены — в `src/data.js`.
