# Galerie

Minimal online gallery for original paintings by contemporary artists — React + Vite, English / French.

- Works grid on white, artwork page (zoom, previous / next), sold works marked with a red dot
- Cart (each work is unique), checkout with shipping & payment choice, order confirmation
- About / shipping & returns / privacy pages
- Language switch EN / FR (auto-detected from the browser)

## Content

The current works and artists are **placeholders** generated by `scripts/placeholder-paintings.py`.
To add real works:

1. Put two images per work in `public/art/`: `<id>-s.webp` (640 px wide) and `<id>-l.webp` (~1400–2000 px wide).
2. Describe the work in `src/artworks.js` (artist, title in EN/FR, year, medium, size, price in €, `sold`, `ratio` = height / width).

Shop name, contacts and currency — `src/config.js`. All interface texts — `src/i18n.jsx`.

## Receiving orders

Create a form on [Formspree](https://formspree.io) (or any service accepting JSON POST) and add its URL in the repository:
**Settings → Secrets and variables → Actions → Variables → `ORDER_ENDPOINT`**, then re-run the deploy.
Without it, checkout opens the visitor's mail client with a pre-filled order to `contactEmail`.

## Development

```bash
npm install
npm run dev
npm run build
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` (Settings → Pages → Source must be **GitHub Actions**).
